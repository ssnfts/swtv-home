# Phase 3 modular architecture implementation plan

Goal: extract six independently buildable libraries, preserve Phase 2 state/behavior, add read-only diagnostics and a versioned navigation-only TV Hub contract. Execute continuously with subagent implementation, task reviews and final project review.

## Global constraints

- Application ID app.swtv.home; minimum SDK29, compile/target35, JVM17; pinned Kotlin2.0.21/AGP8.7.3/Gradle8.9 remain unchanged.
- Preserve preference file home/key config/schema1 and weather cache keys; keep OwnTV default tv.own.owntv and explicit GitHub releases fallback.
- Preserve guarded typed passthrough inputs, bounded workers, D-pad behavior and stock-launcher recovery position.
- No streaming, playlist/EPG processing, APK downloading/installing, release signing/publishing, physical-TV commands or HOME/system changes.
- Only app may own the MainActivity/application manifest. Libraries cannot depend on app or import MainActivity/its BuildConfig/R.

## Task 1: extract independent libraries and UI host

Files: root/settings/app build scripts; new theme-config, app-discovery, launcher-ui, device-diagnostics, update-manager, tv-hub-contract module build/manifest files; moved Kotlin/tests; scripts/verify-module-boundaries.py.

- [ ] Write/run the architecture guard against the single-module project and record its expected missing-module failure. Guard six Android library modules, directed acyclic dependencies, no library-to-app edge/import, UI dependencies limited to theme-config/app-discovery.
- [ ] Add com.android.library8.7.3 to root and six API29/SDK35/JVM17 libraries. App depends on all six; launcher-ui depends on theme-config and app-discovery; other libraries have no project dependencies.
- [ ] Theme owns LauncherConfig/ModuleTile/ConfigCodec/Preferences and ThemePolicy (effects/daylight/boundary). Discovery owns AppEntry, CatalogRules, Discovery, DockPolicy, CatalogPicker and InputPolicy/InputIntents. UI owns HomeUi/SettingsController, Icons/IconWorkPolicy, Wallpaper/LatestResource, Weather/WeatherCacheState/WeatherRequests, WidgetPolicy(refresh/URL) and FocusPolicy.
- [ ] Use namespaces/packages app.swtv.theme, app.swtv.discovery, app.swtv.launcher.ui/runtime, app.swtv.diagnostics, app.swtv.updates, app.swtv.tvhub.contract. Split AppEntry from configuration file. No obsolete duplicate definitions remain in app.
- [ ] Define LauncherHost in launcher-ui with val activity:Activity, config:LauncherConfig, apps:List<AppEntry>, inputs:List<InputEntry>, dockPackages:List<String>, discovery:Discovery; functions save(config), notice(title,message=title), pickWallpaper(). MainActivity implements it; SettingsController uses host/activity separately. No callback reaches back into MainActivity by cast.
- [ ] Move/split all existing JVM tests into owning modules, retain every assertion. Tests mixing responsibilities must be split with equivalent checks. Preserve actual API29 input instrumentation through imports of the moved public input builder.
- [ ] Add a Phase2 schema1 fixture compatibility test, with dock, modules, hidden, weather opt-in, wallpaper URI, IPTV target and settings roundtrip. Preference storage names stay exact.
- [ ] Set development version0.2.0/code2; keep app identity/signing. About uses BuildConfig version rather than hardcoded0.1.0.
- [ ] Run architecture guard, all-module testDebugUnitTest/assembleDebug/lintDebug and app assembleDebugAndroidTest. No connected-device task. Commit only task files; write task1 report with commands/results and mapping.

## Task 2: diagnostics, update provider and TV Hub protocol

Files: device-diagnostics, update-manager, tv-hub-contract implementations/tests; app assembly and UI host callbacks; TV_HUB_INTERFACE.md and architecture docs.

- [ ] Write behavioral tests before new policies/formatters: unavailable diagnostic values, update Unconfigured state/build identity, strict Hub major metadata, request destinations/allowed extras, disabled/unexported/wrong-package/ambiguous handlers and compatible/minor/incompatible-major cases.
- [ ] Implement diagnostics on demand: public Build manufacturer/model/board/ABI/API; display; ActivityManager OS memory and process PSS; StatFs of app files. No identifiers/accounts/private files/ADB or privilege changes. Format missing values honestly.
- [ ] Implement BuildIdentity and UpdateProvider/UpdateState.Unconfigured. No network, installer or signing implementation. About/Updates reports actual build identity and unconfigured release updates.
- [ ] Contract major1/minor0, expected package app.swtv.tvhub, action app.swtv.tvhub.action.OPEN_HUB, application metadata app.swtv.tvhub.contractMajor integer1, request extras major1/destination home only. Only enabled/exported expected-package handler allowed; resolve uniquely and explicitly set component/package. Distinguish Missing/Incompatible/Unavailable/Launched; catch race/launch errors. No normal-launch fallback that bypasses metadata checks; OwnTV remains separate.
- [ ] Document provider manifest declaration, request fields, versioning/minor extension/major rejection rules, reserved future M3U/XMLTV/matching/Media3/cache/favorites capabilities and no credential-bearing IPC/publisher-identity guarantee.
- [ ] Wire diagnostics and updates to explicit user-opened screens; wire TV Hub tile through contract client. Extend LauncherHost callbacks to avoid module cycles. Preserve missing-Hub explanation and OwnTV behavior.
- [ ] Add actual API29 instrumentation for contract outgoing action/package/extras without launching external apps; retain typed-input test. Build tests, never run connectedDebugAndroidTest. Commit and report.

- [ ] Review each implementation against its scope, resolve Important issues, then do final independent project review.

- [ ] Verify every library compiles independently, module graph guard, unit results, lint, APK identity/API/only INTERNET/no JNI/debug signer. Record known warnings/limits and retain poor-emulator-performance caveat.
